# YouOnAI

This repository is a shared workspace for developing research ideas into experiments and products.

## Repository map

- [Discussion notebook](research/discussions/README.md): ideas, responses, sources, and open questions.
- [Current context](collaboration/CURRENT.md): compact handoff for another session or computer.
- [Agent workflow](agents/README.md): roles, token-conscious delegation, and validation.

- [`research/`](research/README.md): source notes, literature, project briefs, and new material awaiting organization.
- [`experiments/`](experiments/README.md): reproducible simulation and model evaluations.
- [`data/`](data/README.md): dataset conventions and local-data boundaries.
- [`product/`](product/README.md): applications and prototypes that grow out of the research.

## Working across computers

Clone the repository and use Git for notes, source code, configurations, and compact experiment results. Large datasets, checkpoints, generated simulation assets, and credentials stay outside ordinary Git; their locations and reproduction steps belong in `data/` or the relevant experiment README.

The existing lecture images are versioned because they are the source archive for the current research. Future bulk data should follow the storage policy in [`data/README.md`](data/README.md).
