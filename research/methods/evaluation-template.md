# Evaluation template

## Claim

State the falsifiable claim and the decision it will inform.

## System under test

Record model, checkpoint, prompts, observation space, action space, controller, simulator version, hardware, and all human assistance.

## Baselines

Include the simplest conventional system, a strong task-specific method, and an oracle or upper bound when possible.

## Scenarios

Separate training conditions, in-distribution evaluation, controlled perturbations, and out-of-distribution evaluation.

## Metrics

Report task success, safety violations, interventions, latency, compute, recovery, calibration, and uncertainty. Preserve per-trial results as well as aggregates.

## Failure analysis

Classify failures by perception, state estimation, planning, control, embodiment mismatch, simulator error, and interface error.

## Reproduction

List code revision, configuration, random seeds, data versions, and exact commands.
