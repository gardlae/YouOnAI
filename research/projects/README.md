# Research projects

Each active direction gets its own folder. A project should contain:

- a precise question and motivation;
- assumptions and competing hypotheses;
- related work and source links;
- the smallest useful experiment;
- baselines, metrics, and failure cases;
- a decision log;
- a path from research result to a possible product.
