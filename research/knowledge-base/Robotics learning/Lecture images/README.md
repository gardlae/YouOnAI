# Robotics learning lecture images

The 118 robotics and embodied-AI images are grouped by capture date and slide topic under `Robotics and embodied AI`.

The sequence covers physical-AI data, embodied reasoning, behavior cloning, multimodal learning, reinforcement learning, data scale, VAM/VLA architectures, the robotics industry, and closed-loop VLA planning. Original filenames and image formats are preserved within each dated folder.
