# Working with a Persistent Shared Object

- Core idea: AI should write to a shared work object, not just answer in chat
  - Human can read, edit, and redirect; AI reads back and iterates
  - Work product keeps developing rather than being rebuilt from scratch
- Supported formats: Markdown, Word, Excel, Google Docs, Notion, JSON, SQL, Airtable, code
- Two main workflow patterns:
  - Iterative refinement: AI writes, human critiques, AI fixes, repeat
  - Memory log: accumulate intermediate notes, convert to final output at the end
- “Amateur” version: chat only, output is a black box with no audit trail

# AI as Cognitive Partner

- AI is sycophantic by default: tends to agree with whatever is input
- Reusable prompt pattern to counter this: “Act as a Socratic tutor. Don’t rewrite my statement. Tell me the logical flaw.”
- Example tested: “AI will replace all software coders in 5 years”
  - With Socratic prompt: AI challenged the static definition of coding, raised demand-scaling and role-shift arguments
  - Refined output: coding shifts from syntax to orchestration; math/systems knowledge grows in importance

# AI Governance and Disclosure

- Goal: record enough to understand, review, and reproduce what happened
  - Track: task, prompt pattern, AI contributions, human revisions, final work product
- Disclosure summary: high-level recap of what AI did vs. what the human decided
- Disclosure log: row-by-row record of each turn in the conversation
- Instructor demonstrated live: generated a disclosure summary from the Coca-Cola website exercise
- Kunal’s observation on context drift:
  - Long conversations cause AI to lose attention on middle content
  - Recommended fix: log after every turn, then summarize across logs rather than summarizing all raw input at once

# Project Overview and Week 2 Assignment

- Project categories:
  - Commercialization / corporate innovation / AI-enabled product
  - Research acceleration tool (any discipline)
  - Studio: art, music, video (note: high token burn rate for media)
- Project is individual; peer feedback encouraged but not a group project
- Final deliverable = artifact + governance log of how AI was used
- Week 2 assignment (due Sunday):
  1. Draft 3 problem hypotheses: observed trend, who has the problem, proposed solution
  2. Validate each with both AI and at least one human
  3. Use AI in persona mode: “Act as a person who works in X role. Would this help you?”
  4. Turn in a disclosure summary or log of the AI brainstorming session
- Clarification: final project does not need live AI components; building with AI assistance is sufficient
- Assignments build on each other; Week 1 was the starting conversation, Week 2 adds 3 ideas and human validation
