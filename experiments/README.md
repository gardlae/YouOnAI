# Experiments

Create one folder per executable experiment using a stable name such as `underwater-valve-baselines/`.

Every experiment should include:

- a README with the hypothesis and exact reproduction command;
- versioned configuration files;
- source code and lightweight fixtures;
- a manifest for external data, checkpoints, and simulator assets;
- compact metrics and plots suitable for Git;
- a link to the research project it tests.

Large outputs belong in ignored `runs/` or external object storage.
